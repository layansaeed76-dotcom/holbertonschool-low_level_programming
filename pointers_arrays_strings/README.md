# Pointers, Arrays and Strings

This directory contains C exercises about pointers, arrays and strings.

## Files

- `0-reset_to_98.c`: function that updates the value pointed to by an `int` pointer to 98.
- `main.h`: header file with function prototypes.

## Compilation

    gcc -Wall -pedantic -Werror -Wextra -std=gnu89 *.c -o program
