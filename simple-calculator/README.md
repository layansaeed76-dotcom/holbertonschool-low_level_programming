# Simple Calculator

A simple command-line calculator written in C.

## Description

The program prints a welcome line and a menu (Add, Subtract, Multiply, Divide, Quit),
then reads the user's choice. Choosing `0` quits the program.

## Number Type

The calculator uses decimal numbers (`double`) for all operations.
Results are printed with `%g`, so whole numbers appear without a decimal
part (for example `35`) and fractions appear normally (for example `2.5`).

## Division by zero

If B is 0 on division, the program prints `Error: division by zero`
and returns to the menu.
